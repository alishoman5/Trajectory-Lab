# Presentation-reported results

These values were transcribed from slides 23, 37 and 38 of `3rd Presentation.pptx`. The source deck labels ATE in metres and RPE in percent.

The deck describes alignment using a similarity transform with optional lever-arm and time-shift estimation. This differs from the current exported application's rigid Trajectopy alignment policy. The values are retained as historical project evidence and have not been independently recomputed from the underlying trajectories in this repository.

`metrics.csv` contains the exact values printed on the individual dataset slides. The summary chart in slide 30 rounds some labels to two or three decimal places.
